# PokerCat2

Mobile-first web prototype for a Korea-focused holdem player social network.

## V0 scope
- First-visit login shell with Google / Kakao / Apple buttons
- Onboarding: choose 1 of 9 placeholder PokerCat avatars
- Lightweight poker profile: nickname, preferred game, online/offline preference
- Social feed with demo accounts and posts
- Standardized hand-history cards inside the feed
- Hand-history composer + preview
- Explore tab placeholder
- Tournament schedule tab with sample events
- Poker-focused user profiles
- Follow/unfollow, likes, simple social interactions
- Light / dark mode
- Mobile bottom navigation
- LocalStorage-based demo state

## Run
Open `index.html` directly, or serve the repository with any static web server.

No backend or real social login is connected in this V0.
